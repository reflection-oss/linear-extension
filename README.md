# Mirror × Linear

Browse your Linear project's issues inside Mirror. Read-only, with automatic refresh.

## Installation

Run in Mirror:

```text
/extensions-add https://github.com/reflection-oss/mirror-example-extension
```

Approve the extension. Connect Linear with `/connect linear` if needed.

## Use

Press **F8** or run **`/linear`**. Choose a project once; your choice is remembered.

- **↑↓** — select an issue; **Enter** — open it in Linear.
- **/** — search; **Tab** — filter by status.
- **Esc** — close.
- **`/linear project`** — switch projects.
